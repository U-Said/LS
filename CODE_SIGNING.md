# Code signing policy

- **Builds.** Release files are built only by GitHub Actions from the tagged sources of this repository ([build.yml](.github/workflows/build.yml)), never on a personal computer. Only these builds are signed, and every signing request is approved by hand.
- **Committers and reviewers:** [U-Said](https://github.com/U-Said). Changes from other people (pull requests) are reviewed before they are merged.
- **Approvers:** [U-Said](https://github.com/U-Said).
- **Privacy:** This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it. See [PRIVACY.md](PRIVACY.md).
- **Uninstall:** see the README, section [Uninstall](README.md#uninstall).

---

## Политика подписи кода

- **Сборки.** Файлы выпусков собирает только GitHub Actions из исходников этого репозитория с тегом выпуска ([build.yml](.github/workflows/build.yml)), а не чей-то компьютер. Подписываются только такие сборки, и каждый запрос на подпись утверждается вручную.
- **Изменения вносит и проверяет** [U-Said](https://github.com/U-Said). Чужие изменения (pull requests) проверяются перед принятием.
- **Подпись утверждает** [U-Said](https://github.com/U-Said).
- **Конфиденциальность:** программа ничего не передаёт по сети, пока пользователь сам этого не попросит. Подробно — в [PRIVACY.md](PRIVACY.md).
- **Удаление:** README, раздел [«Удаление»](README.md#удаление).
